# GENESIS - AI Schedule Builder

A fully client-side web application that builds a complete, P6-importable baseline schedule from a project BOQ.

## Features Built
- 100% Client-side processing (React + Zustand).
- Custom Deterministic CPM & Calendar Engines.
- Zone-based proportional quantity distribution.
- XER format exporter round-trip compatible with Primavera P6.
- Interactive Gantt and DCMA Scorecard validation.
- Mocked AI integration via prompt interfaces.

## Scripts
- `npm run dev`: Start dev server
- `npm run build`: Compile and minify for production
- `npm run test`: Run the Vitest test suite

## Data Mocks
Logic-bank references and seeded data models are currently mocked in the codebase structure to support isolated execution.
